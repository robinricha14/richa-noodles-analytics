# Portfolio — NoodlesCrypto Power BI Analytics Project

## Project Summary
This project demonstrates end‑to‑end BI development using MySQL, Python, and Power BI. It analyzes cryptocurrency engagement across Twitter and Reddit, providing insights into token popularity, platform performance, and time‑based trends.

---

## Objectives
- Build a parameterized Power BI report  
- Implement advanced DAX measures  
- Create drill‑through and interactive filtering  
- Produce professional documentation  
- Deliver a portfolio‑ready analytics project  

---

## Technical Stack
- **Power BI Desktop**  
- **MySQL (noodles_dw)**  
- **ODBC Connector**  
- **Python (Task 6 preprocessing)**  

---

## Data Model
The model includes:
- 3 dimension tables  
- 4 reporting views  
- 6 relationships  
- DimDate marked as date table  

This structure enables time intelligence, platform analysis, and currency drill‑downs.

---

## Report Pages

### 1. Executive Dashboard
High‑level KPIs and top‑performing tokens.

### 2. Time Series Analysis
Daily engagement trends and activity volume.

### 3. Platform Analysis
Comparison of Twitter vs Reddit engagement and quality.

### 4. Currency Deep Dive
Token‑specific analysis with drill‑through navigation.

---

## DAX Highlights
- Total Engagements  
- Avg Engagement Score  
- Engagement per Post  
- 7‑day and 30‑day averages  
- Engagement Rank  
- Platform Share %  

All measures are documented in `docs/dax-measures-list.md`.
