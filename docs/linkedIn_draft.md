# LinkedIn Post Draft — Noodles Crypto Analytics

I’m excited to share my latest Business Intelligence project: **Noodles Crypto Analytics**.

The goal was to turn fragmented cryptocurrency market and social-engagement data into a trusted, executive-ready analytics solution.

### What I built

- Designed a dimensional data warehouse using MySQL
- Built Python/Jupyter data-preparation and validation workflows
- Created reporting views for market, time-series, platform, and currency analysis
- Developed interactive Power BI dashboards
- Implemented DAX measures for KPIs, rankings, averages, and platform analysis
- Added drill-through, filtering, and stakeholder-focused dashboard navigation
- Documented the architecture, data dictionary, technical runbook, and dashboard usage

### What I learned

This project strengthened my practical skills across the full analytics lifecycle — from data preparation and modeling through visualization, DAX, data quality, and executive storytelling.

One of the biggest takeaways was that a good dashboard starts well before the visualization layer. A reliable data model, clear validation process, and documented pipeline are essential for producing trustworthy insights.

### Key analytical takeaway

Social engagement can act as a useful indicator of attention and momentum, while platform and currency-level analysis helps explain where that activity is coming from.

The final solution is designed to make these patterns easier for analysts and decision-makers to explore.

**Tech stack:** Python | MySQL | Power BI | DAX | Jupyter | Git/GitHub

I’m continuing to improve the portfolio by refining the demo walkthrough, documentation, and public repository presentation.
